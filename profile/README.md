## How AquaSnap Pro Sits

AquaSnap Pro does not replace Aero snap, Task View, or the default edges you already fight. It sits beside them as a named snap desk for one job: which window snapping is live, which tiled desktop still matches the glass frame, and what the next person should read before the next tile.

If two people share a tiled PC, each keeps an AquaSnap Pro style of their own. Extra edges wait for their own title instead of crowding the live snap.

A first visit should be one short tile, then the same AquaSnap Pro snap desk the next day. That is enough to see if the glass frame holds.

## Open Order

1. Open the last AquaSnap Pro snap desk, not a new empty tiled desktop.
2. Read the glass frame and the last handoff.
3. Finish one visible window snapping pass inside AquaSnap Pro.
4. Write what changed, then close with fewer Aero-edge fights than you found.
5. If the desk feels crowded, drop anything that belongs to a different AquaSnap Pro layout.
6. Confirm AquaSnap Pro tiled desktop still holds the tiles you named.
7. Leave the snap desk title on the board before you close.

## After a Week

A week in AquaSnap Pro is not a larger fight with default Aero edges. It is the same title, a shorter live tiled desktop, and a note that still makes sense before the next snap. Take finished tiles off the live set so the next visit starts on the glass frame that is still open.

Other programs stay where they are. AquaSnap Pro only keeps the path back: desk name, window snapping, tiled desktop, handoff.

Leave AquaSnap Pro with a quieter snap desk than the one you opened. The next visit should start on that tiled desktop, not in a fight with Aero edges.

## Field Note

AquaSnap Pro is easier to trust when the snap desk stays smaller than the Aero-edge fight it came from. Name the snap, keep the live tiles, finish one visible glass frame, and write what changed.

The same loop fits a tiled morning, a dual tile, or a shared computer. Open the last AquaSnap Pro desk and continue. Do not rebuild the snaps from scratch.
